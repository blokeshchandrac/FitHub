## Authorization summary

- Administrator assignment endpoints require the `Administrator` policy.
- Trainer plan and assigned-Member endpoints require the `Trainer` policy and perform a persisted assignment check for every Member ID.
- Member personal workout-template and session endpoints remain Member-only and do not become trainer catalogue endpoints.
- Recommendation endpoints require both the `Member` and `ActiveMembership` policies and derive the Member ID only from the authenticated principal.
- Profile writes derive the Member ID only from the authenticated principal; request payloads cannot select another user.

## Migration

`20260908155406_AddTrainerAssignmentsAndTrainingProfile` adds the branch catalogue, historical Trainer–Member assignments, training-profile columns, workout-template ownership kind and workout-plan assignment end time. Existing data is retained. Existing Member profiles are marked incomplete because the newly required values cannot be safely invented; development demo accounts are completed only by the Development seeder.
