How to play

Smart Equipment Virtual Lab

  1. Refresh Members to load existing Member names and statuses from the development FitHub database.
  2. Choose a session-only status scenario, then scan that Member’s card at the entrance.
  3. Click the avatar to select it. Move with WASD, arrow keys, or pointer dragging; hold Shift for a small speed boost.
  4. Double-click the avatar, take its card, then drag it onto a machine’s TAP HERE reader.
  5. Move every assigned Member outside the blue sensor volume. A real-time 30-second clearance countdown starts.
  6. Return during the countdown to cancel it, or remain clear until automatic release completes.
  7. Select workbench wires to test power, PN532, sensor, and LED failures without changing Member database records.

Local Mode applies rules in this browser after loading the development Member catalogue. Connected Mode also validates current database status and sends isolated simulation events through the API and SignalR hub.
